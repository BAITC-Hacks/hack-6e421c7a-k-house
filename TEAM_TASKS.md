## Задача для друга — AI-модуль

**Цель:** заменить локальные шаблонные вопросы на настоящую функцию OpenAI.

### Что реализовать

1. Создать API endpoint (например, `/api/analyze-task`).
2. Получить короткий черновик задачи от бизнеса.
3. Отправить в OpenAI промпт, который возвращает строго JSON:
   ```json
   {
     "questions": ["...", "...", "..."],
     "missingFields": ["users", "data", "success"]
   }
   ```
4. Не добавлять факты, которых нет в сообщении пользователя.
5. Валидировать JSON. При ошибке показать понятное сообщение и оставить ручной режим вопросов.
6. Добавить `.env.example` только с `OPENAI_API_KEY=`; реальный ключ никогда не коммитить.
7. Описать в README: промпт, формат input/output и fallback.

### Критерий готовности

На одном слабом описании («Нужен сайт для учёта заказов») AI выдаёт минимум три уместных уточняющих вопроса. Если API выключен, сайт не ломается.
