# TaskBridge AI

> AI-платформа, которая помогает бизнесу превращать размытые запросы в готовые задачи для студенческих команд.

## Проблема

Бизнес часто формулирует задачу слишком кратко: не указаны пользователи, данные, ожидаемый результат, критерии успеха или ограничения. Студенческим командам сложно понять, за что браться, а сильные практические задачи теряются.

## Решение

TaskBridge AI проводит бизнес через короткое уточнение задачи, формирует **редактируемую карточку**, считает прозрачный рейтинг готовности и публикует задачу в общем каталоге. Команды сами выбирают интересные задачи и отправляют предложения. Решение о выборе всегда остаётся за бизнесом.

## Сквозной сценарий

1. Бизнес вводит черновое описание задачи.
2. AI определяет пробелы и задаёт не менее трёх уточняющих вопросов.
3. Бизнес заполняет и вручную подтверждает редактируемую карточку.
4. Прозрачный рейтинг (0–100) пересчитывается после каждого изменения.
5. Задача публикуется в каталоге.
6. Студенческая команда отправляет идею, план, срок и ссылку на прототип.
7. Бизнес вручную выбирает или отклоняет отклик.

## Формула рейтинга

| Поле | Баллы |
| --- | ---: |
| Контекст и потребность | 20 |
| Данные и материалы | 20 |
| Ожидаемый результат | 15 |
| Критерии успеха | 15 |
| Ограничения | 10 |
| Пользователи | 10 |
| Контакт и формат взаимодействия | 10 |
| **Итого** | **100** |

Баллы начисляются только за заполненные и подтверждённые поля.

## AI-границы

- AI не добавляет факты, которых не сообщил бизнес.
- AI предлагает только уточняющие вопросы и структурирует полученные ответы.
- Карточка редактируется и подтверждается человеком до публикации.
- AI не назначает исполнителей и не выбирает команду за бизнес.

## Студенческий сценарий

- **Каталог** — опубликованные задачи, по умолчанию сначала с высоким рейтингом. Фильтры по теме и уровню готовности, сортировка по рейтингу.
- **Карточка задачи** — все 7 полей с баллами. Поля, которые бизнес не заполнил, видны сразу: команда понимает, что придётся уточнить.
- **Отклик** — название команды, идея, план, срок, ссылка на прототип. Одна команда не может откликнуться на одну задачу дважды.
- **Решение бизнеса** — отклики сгруппированы по задачам, есть фильтр по статусу. Кнопки «Выбрать команду», «Отклонить» и «Вернуть на рассмотрение» нажимает только человек.
- **Демо-данные** — `data/seed.json`: 5 задач с разным рейтингом, 5 команд, 5 откликов. Кнопка «Восстановить демо-данные» в каталоге возвращает исходное состояние.

## Технологии

- HTML, CSS, JavaScript — интерактивный MVP без сборки;
- Node.js (`server.js`) — статический сервер и endpoint `/api/analyze-task`, без внешних зависимостей;
- OpenAI API — генерация уточняющих вопросов в строгом JSON; если API недоступен, сайт переключается на ручные вопросы;
- localStorage — сохранение задач и откликов во время демо.

## Структура

| Файл | Что внутри |
| --- | --- |
| `index.html`, `styles.css` | экраны и дизайн |
| `app.js` | бизнес-сценарий: черновик, карточка, рейтинг, публикация |
| `ai-client.js`, `server.js` | AI-уточнение и безопасный fallback |
| `student-flow.js` | каталог, карточка задачи, отклики, решение бизнеса |
| `data/seed.json`, `data/schema.sql` | демо-данные и схема для будущей БД |

## Запуск

Нужен Node.js 18+:

```bash
npm start
```

Откройте `http://localhost:3000`.

Чтобы включить AI, перед запуском задайте ключ в переменной окружения (пример — `.env.example`, реальный ключ не коммитим):

```bash
# macOS / Linux
OPENAI_API_KEY=sk-... npm start
# Windows PowerShell
$env:OPENAI_API_KEY="sk-..."; npm start
```

Без ключа сайт полностью работает в ручном режиме уточнения.

## Тестовый сценарий демо

**Бизнес:**
1. Открыть «Создать задачу».
2. Ввести: «Нужен сайт для учёта заказов».
3. Ответить на вопросы AI и заполнить карточку.
4. Показать рост рейтинга и расшифровку баллов.
5. Опубликовать задачу — она появляется в каталоге.

**Студенческая команда:**
6. В каталоге отфильтровать задачи по теме и готовности.
7. Открыть «Подробнее»: видно, за что задача получила баллы и чего в ней не хватает.
8. Нажать «Откликнуться», заполнить идею, план, срок, ссылку на прототип.

**Решение бизнеса:**
9. Открыть «Мои отклики», отфильтровать «Ожидают».
10. Вручную выбрать одну команду и отклонить другую. Автоматического назначения нет.
