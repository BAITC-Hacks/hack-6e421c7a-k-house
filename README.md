# TaskBridge AI

> AI-платформа, которая помогает бизнесу превращать размытые запросы в готовые задачи для студенческих команд.

## Проблема

Бизнес часто формулирует задачу слишком кратко: не указаны пользователи, данные, ожидаемый результат, критерии успеха или ограничения. Студенческим командам сложно понять, за что браться, а сильные практические задачи теряются.

## Решение

TaskBridge AI проводит бизнес через короткое уточнение задачи, формирует **редактируемую карточку**, считает прозрачный рейтинг готовности и публикует задачу в общем каталоге. Команды сами выбирают интересные задачи и отправляют предложения. Решение о выборе всегда остаётся за бизнесом.

## Сквозной сценарий

1. Бизнес вводит черновое описание задачи.
2. AI определяет пробелы и задаёт не менее трёх уточняющих вопросов.
3. Бизнес заполняет и вручную подтверждает редактируемую карточку.
4. Прозрачный рейтинг (0–100) пересчитывается после каждого изменения.
5. Задача публикуется в каталоге.
6. Студенческая команда отправляет идею, план, срок и ссылку на прототип.
7. Бизнес вручную выбирает или отклоняет отклик.

## Формула рейтинга

| Поле | Баллы |
| --- | ---: |
| Контекст и потребность | 20 |
| Данные и материалы | 20 |
| Ожидаемый результат | 15 |
| Критерии успеха | 15 |
| Ограничения | 10 |
| Пользователи | 10 |
| Контакт и формат взаимодействия | 10 |
| **Итого** | **100** |

Баллы начисляются только за заполненные и подтверждённые поля.

## AI-границы

- AI не добавляет факты, которых не сообщил бизнес.
- AI предлагает только уточняющие вопросы и структурирует полученные ответы.
- Карточка редактируется и подтверждается человеком до публикации.
- AI не назначает исполнителей и не выбирает команду за бизнес.

## Технологии

- HTML, CSS, JavaScript — интерактивный MVP без сборки;
- localStorage — локальное сохранение демонстрационных задач и откликов;
- OpenAI API — следующий этап для генерации уточняющих вопросов и сборки карточки.

## Запуск

Откройте `index.html` в браузере или запустите:

```bash
python3 -m http.server 8080
```

Затем перейдите на `http://localhost:8080`.

## Тестовый сценарий демо

1. Открыть «Создать задачу».
2. Ввести: «Нужен сайт для учёта заказов».
3. Ответить на вопросы AI и заполнить карточку.
4. Показать рост рейтинга и расшифровку баллов.
5. Опубликовать задачу.
6. В каталоге открыть её и отправить отклик команды.
7. Вручную выбрать или отклонить отклик.

## Раскрытие внешних компонентов

Используются стандартные браузерные API. Планируемое подключение OpenAI API применяется только для AI-уточнений и структуры карточки. В рамках хакатона разработка ведётся с использованием Codex.
